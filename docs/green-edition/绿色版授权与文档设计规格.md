## 1. 目标与边界

### 1.1 目标

把「老殷工控 PLC 助手」做成可分发给客户的**绿色软件包**：

- 客户解压 ZIP、双击 EXE 即可使用，无需安装、无需执行批处理、无需预装 Node.js / Python / 运行库；
- 客户必须使用**自己的 API Key**，程序目录内不存在任何可用密钥；
- 客户从首次启动起可用 **60 天**，到期进入**安全只读模式**；
- 需求方本人拥有**管理员授权**，不受 60 天限制，且该机制**不向客户展示**；
- 普通客户看不到源代码，无法直接复制或修改程序文件；
- 客户系统全部自动适配（见第 8 章）；
- 交付完整文档体系：软件内置帮助 + 客户 PDF + 可编辑源文档，配合真实截图教程。

### 1.2 硬性边界

- **零中断**：授权改造不能阻断现有软件在任何一台电脑上的使用；授权服务未准备好前，不锁住任何用户。
- **不购买云服务器（本轮）**：在线授权服务按标准 HTTPS 接口先行设计并本机测试，云部署留待后续另行决定。
- **不混工单**：本规格不修改 BOM/CTU_INT/互斥队列等既有核心逻辑；实现时另立工单。
- **不加依赖**：实现阶段不引入新的 npm 依赖（除非需求方另行批准）。

### 1.3 安全边界（如实声明）

纯本地、无服务器的前提下，无法同时做到「任意客户复制即用」和「绝对无法重置 60 天」。本方案可阻止普通用户通过重新解压、删除目录、回拨系统时间续期；但专业用户通过重装系统、虚拟机快照或逆向修改仍可能绕过。授权服务器上线后才具备更强控制。此边界必须写入客户故障排查文档。

## 3. 开发语言与技术架构

### 3.1 现有系统实际技术栈（已核实）

| 层 | 语言 / 技术 | 说明 |
|---|---|---|
| 主后端 | JavaScript / Node.js 22+ | Express 4、认证、AI 调用、路由、MCP 客户端、日志 |
| 用户界面 | HTML5 + CSS3 + JavaScript（ES Modules） | 原生前端，无大型框架 |
| 博途桥接 | C# / .NET Framework 4.8 | TIA Portal Openness MCP 服务 |
| 工程导入引擎 | PowerShell | EngineerYin 常驻 Worker、SCL/STL/S7DCL 导入 |
| 数据层 | SQLite（node:sqlite） | 用户、配置、业务数据 |
| 进程协议 | JSON / JSONL | 主程序与 Worker、MCP 之间通信 |

### 3.2 绿色版新增技术

| 能力 | 技术选型 | 用途 |
|---|---|---|
| API Key 加密 | Windows DPAPI | 密钥只对当前 Windows 用户可解密 |
| 设备指纹 | CPU / 磁盘 / 网卡 / 系统标识组合 | 授权绑定设备 |
| 许可证签名 | Ed25519 | 主程序只内置公钥，私钥在需求方手中 |
| 授权通信 | HTTPS + 签名 JSON | 未来在线激活与周期校验 |
| 源码保护 | Node.js SEA 单文件 + 资源压缩混淆 + SHA-256 完整性校验 | 隐藏散装源码 |

### 3.3 封装路线（已确认：方案 A）

采用 **Node.js SEA（Single Executable Application）单文件主程序**：

- 主程序与 Web 资源嵌入一个 EXE；
- C# / PowerShell 引擎作为受完整性校验的签名资源，按需释放到系统临时目录；
- 不重写现有 PLC 核心逻辑；
- 发布包不含 `server.js`、`routes/*.js`、`web/*.js` 等散装源码。

> 说明：纯本地软件无法承诺对专业逆向「绝对不可破解」；目标是普通用户不可读、不可直接改，并提高专业逆向成本。
> 绿色包原型 v0.1 暂以「自包含运行时 + 启动器 EXE」交付，SEA 源码隐藏列入阶段 5。

## 4. 零中断过渡方案（已确认）

### 4.1 当前阶段（无授权服务器）

- **需求方电脑**：使用管理员授权（见第 5 章），不依赖云服务器。
- **客户电脑**：首次启动建立**本地 60 天试用凭证**，状态保存在 Windows 用户数据目录（不在绿色程序文件夹内）。
- 重新解压 / 重新复制程序到**同一台电脑**，不会重新获得 60 天。
- 客户必须填写自己的 API Key。

### 4.2 未来阶段（授权服务器上线后）

- 后台发现授权服务可用时，自动登记本地原始开始日期，换取服务器签名凭证；
- 剩余天数保持不变，**无感迁移**；
- 迁移失败或服务器不可用时，原本地许可继续工作；
- 绝不因授权服务未准备好而锁住客户。

### 4.3 试用状态存储

- 存储位置：`%LOCALAPPDATA%\老殷工控PLC助手\license\`（每台电脑独立）；
- 字段：设备指纹、首次启动时间、最后可信时间、到期时间、状态；
- 防改时：记录最后可信时间，回拨系统时间超过阈值时要求重新校准；
- 防重装：状态同时以 Windows 系统级标识（非程序目录）参与绑定。

## 5. 管理员授权隔离（已确认）

### 5.1 命名与可见性

- 原「永久老板授权」统一改称**管理员授权**；
- 客户绿色包中**不展示、不说明、不提供**管理员授权入口；
- 客户文档中不出现管理员授权章节；
- 客户界面授权区只显示「试用中 / 正式授权 / 已到期」状态。

### 5.2 授权模型

- 管理员授权由**独立签发工具**生成，绑定需求方设备；
- 许可证以签名文件形式存放于系统数据区，**不进入绿色程序文件夹**；
- 主程序只内置签名公钥，静默验证管理员授权；
- 复制需求方程序目录到别的电脑，**不会带走**管理员权限。

### 5.3 工具隔离

需求方单独保管的管理员工具包（不进客户包）：

```text
老殷授权管理器.exe
管理员授权说明.pdf
客户续期与设备管理工具
发布签名工具
签名私钥（独立加密保存）
```

### 5.4 安全铁律

- 主程序只内置公钥，不能签发许可证；
- 私钥与管理员工具永不进入客户包；
- 不使用硬编码万能密码或隐藏后门；
- 所有管理员能力同时校验签名许可与设备绑定；
- 客户包复制后不携带管理员权限或 API Key。

## 6. 客户 60 天试用与到期行为（已确认：方案 A 安全只读）

### 6.1 试用

- 客户首次启动后自动开始 60 天试用；
- 试用期可正常使用全部功能（AI 生成、TIA 写入、建工程、下载、危险工具等）。

### 6.2 到期后：安全只读模式

- 停止：AI 调用、TIA 写入、建工程、下载、危险工具；
- 保留：登录、查看历史、查看配置、导出日志、备份本地数据；
- 正在执行的 PLC 操作先安全收尾，不中途强杀进程；
- 到期界面显示续期入口与数据导出入口。

## 7. API Key 隔离（已确认）

- 客户在首次启动向导中填写自己的 API 地址、Key、模型；
- Key 使用 **Windows DPAPI** 加密，保存于 `%LOCALAPPDATA%`；
- 界面仅显示掩码（如 `sk-****7K9A`），不提供明文查看；
- 程序文件夹内不保存明文 Key；
- 复制程序目录到其他电脑或 Windows 账户，Key 无法解密，必须重新填写。

自动检测与适配清单：

- 代理网络适配；
- 客户自定义 API 地址、Key、模型及连接测试；
- 首次启动自动生成诊断报告（可一键复制技术信息）。

## 9. 首次启动向导（已确认：方案 A 自动检测 + 分步确认）

八步流程：

1. **欢迎**：说明绿色运行、数据位置与安全边界；
2. **系统扫描**：Windows、路径、权限、端口、防火墙、网络；
3. **TIA 检测**：版本、安装路径、Openness、组件；
4. **授权识别**：需求方管理员授权 / 客户本地 60 天试用；
5. **AI 配置**：客户自己的 API 地址、Key、模型与连接测试；
6. **数据目录**：自动选择可写目录，建立日志与备份位置；
7. **健康检查**：0-100 分、问题清单、自动修复与处理建议；
8. **准备完成**：配置摘要，进入软件并打开快速教程。

交互原则：系统能判断的全部自动完成；只让客户确认授权、API 与异常修复。

## 14. 验收标准

1. 在干净 Windows 10/11（64 位）上，解压 ZIP → 双击 EXE → 完成向导 → 进入软件；
2. 客户填写自己的 API Key 后，AI 与 TIA 功能可用；

6. 客户绿色包中无管理员授权字样、无签发工具、无私钥；
