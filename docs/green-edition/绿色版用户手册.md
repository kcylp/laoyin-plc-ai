# 老殷工控 PLC 助手绿色版用户手册

## 1. 产品概览

老殷工控 PLC 助手是面向工业自动化工程师的本地 PLC 工程工作台，支持：

- AI 辅助生成与解释 PLC 程序；
- S7-200 SMART、S7-1200、S7-1500 项目上下文；
- LAD、FBD、SCL、STL、GRAPH 等语言提示与校验；
- TIA Portal 本机连接、软件树、块描述、读值与安全写入；
- 硬件目录搜索、变量表查看、HMI 工具调用、S7DCL 导出、批量建工程；
- 日志、数据库备份、环境健康检查和故障诊断。

## 2. 开发语言与技术栈

| 层 | 技术 |
|---|---|
| 后端 | JavaScript（Node.js） |
| Web 服务 | Express |
| 数据库 | Node.js 内置 SQLite |
| 前端 | HTML5、CSS3、原生 JavaScript |
| 工业集成 | PowerShell、TIA Portal Openness、MCP |
| 启动器 | C#/.NET Framework WinForms 托盘程序 |
| 后端封装 | Node.js SEA（Single Executable Application） |
| 安全 | JWT、本地访问限制、AES-256-GCM API Key 加密、三级确认 |

运行版不要求客户安装 Node.js 或 npm；TIA 功能仍要求客户机安装兼容的 Siemens TIA Portal/Openness。

## 3. 安装与首次启动

1. 将绿色版 ZIP 完整解压到本地目录。
2. 不要从 ZIP 内直接运行，也不要删除 `app\engine`。
3. 双击 `老殷工控PLC助手.exe`。
4. 启动器检查端口和后端健康状态，成功后自动打开浏览器。
5. 在登录页注册或登录。
6. 登录后进入“设置”，填写客户自己的 AI 服务地址、API Key、协议类型和模型。

程序不会从程序目录读取客户 API Key。Key 加密后保存在当前 Windows 用户目录，拷贝绿色包给其他客户不会带走你的 Key。

## 4. 授权规则

- 首次启动开始 60 天离线试用。
- 试用起始记录位于 `%LOCALAPPDATA%\老殷工控PLC助手`，不在程序目录。
- 授权文件缺失、被修改、机器标识不一致或超过 60 天，程序拒绝启动。
- 到期提示只显示中文业务提示和管理员联系方式，不显示内部路径或堆栈。
- 授权校验不联网，不影响客户在无外网环境下使用本地工程能力。

当前客户包不包含管理员授权工具、私钥或永久授权入口。

## 5. 在线面板使用

### 5.1 连接博途

打开在线面板，点击“连接博途”。程序只对本机 TIA/Openness 发起操作，并显示连接状态、工程名和 TIA 版本。

### 5.2 软件树与变量表

连接后点击“刷新软件树”查看程序块。点击块可在右栏查看上下文。

在“变量表”区域点击“刷新列表”，再点击变量表条目查看内容。没有变量表时显示空列表是正确结果。

### 5.3 硬件搜索

在“硬件管理”输入 `1214C` 或订货号，点击搜索。结果来自 TIA MCP 的 `SearchHardwareCatalog`，最多显示 50 条。选择设备后使用“添加设备”流程。

### 5.4 安全写入

写入 PLC 前必须经过预检、事实确认和危险操作确认。不要跳过确认，也不要在未确认 PLC/IP/目标块的情况下写入。

### 5.5 HMI、建工程与 S7DCL

- “HMI 快捷流程”用于画面、标签绑定、预检、导出和属性描述。
- “快速建工程”先预览 spec，再确认执行。
- 块逻辑右栏的“导出 S7DCL”用于导出文档。

## 6. API Key 与数据备份

- API Key 使用 AES-256-GCM 加密保存，界面仅显示掩码。
- 数据库：`%LOCALAPPDATA%\老殷工控PLC助手\plc_assistant.db`
- 运行日志：程序目录 `app\work\logs\tia-ops.jsonl`
- 数据库备份：程序目录 `app\work\db-backups\plc_assistant.<日期>.db`
- 备份保留最近 7 份。

不要把 `%LOCALAPPDATA%\老殷工控PLC助手` 目录复制给其他客户。

## 8. 退出与故障排查

右击任务栏托盘图标，选择“退出老殷工控PLC助手”。启动器会通知后端停止，后端退出钩子会关闭 MCP、Yin worker 和相关引擎子进程。

常见提示：

- **端口 3000 已被占用**：关闭占用 3000 的程序后重试。
- **授权文件无效**：联系管理员续期，不要手动修改授权文件。
- **TIA 未连接**：确认 TIA Portal 已安装、工程已打开、Openness 权限可用。
- **API 调用失败**：在设置页检查自己的 API 地址、Key、协议类型和模型。
- **启动失败**：查看程序根目录的 `启动日志.txt`，只把业务提示和时间提供给管理员。

## 10. 已知限制

- 当前 SEA 隐藏的是后端 JavaScript；浏览器必须加载的 HTML/CSS/前端 JavaScript 仍作为静态资源存在。
- TIA Openness 和 PowerShell 引擎必须外置，不能塞进 SEA。
- 默认服务端口为 3000。
- 离线试用授权不依赖服务器；管理员续期工具由发行方单独保管。
