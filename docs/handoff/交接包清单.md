# 老殷工控 PLC 助手：源码、绿色包与现场证据交接清单

> 本清单用于收发双方逐项签字/确认。没有实际执行的项目必须写“未执行/受限原因”，不能用“预计通过”替代证据。

## 1. 交付物关系

| 交付物 | 用途 | 是否含源码 | 是否含发行方 Key | 是否需要 Node |
|---|---|---:|---:|---:|
| GitHub `main` | 版本源、审查、后续开发 | 是 | 否 | 开发需要 |
| 源码交接 ZIP | 离线交接、复现、二次开发 | 是 | 否 | 开发需要 |
| 绿色免安装 ZIP | 客户运行 | 否（仅运行资产） | 否 | 不需要 |

三种交付物必须使用客户自己的 AI/API Key、JWT_SECRET、ADMIN_KEY 和邮件授权码。任何凭据都不能从发行方机器目录、数据库、浏览器 LocalStorage 或用户目录复制。

## 2. GitHub 源码包含

- Node.js/Express 后端与 `routes/`、`lib/`；
- 原生 HTML/CSS/JavaScript 前端与 `web/`；
- EngineerYin PowerShell 引擎、公共核心、worker/回退客户端；
- TIA MCP C# 源码、文档、已验证的 V21 runtime 资产；
- 单元/结构测试与测试运行说明；
- `.env.example`（只有占位符，不是配置文件）；
- `tools/diagnose-tia.ps1`、`tools/create-source-handoff.ps1`；
- `docs/handoff/` 全套技术手册、API 安全边界、构建部署、故障排查和接手清单。

## 3. 明确排除

- `.env`、API Key、SMTP/IMAP 授权码、JWT/管理员生产密钥；
- `plc_assistant.db`、SQLite/数据库备份、用户数据；
- `license.json`、`trial.marker` 或任何试用/授权状态；
- `work/logs/*`、诊断报告、浏览器缓存、现场截图（除非单独脱敏批准）；
- `.git`、开发 `node_modules`、绿色 ZIP、stage、测试快照和本机 SEA 工具链；
- 发行方个人邮箱、用户名、路径和机器环境输出。

源码 ZIP 由 `tools/create-source-handoff.ps1` 使用 `git archive HEAD` 生成，再执行二次排除；manifest 的 commit 必须与报告记录一致。

## 4. 绿色包必须包含

~~~text
老殷工控PLC助手.exe
runtime\laoyin-server.exe
app\web\
app\engine\
app\engine\tia-mcp\runtime\v21\TiaMcpServer.exe
app\tools\diagnose-tia.ps1
说明文档\（完整交接/部署/排错文档）
README_请先看.txt
~~~

绿色包不得包含 `server.js`、`sea-entry.js`、`package.json`、`.env`、开发 `node_modules`、数据库、授权文件或运行日志。`app\engine` 是为运行所需的外置资产，不等于把客户的 TIA Portal 安装复制进来。

## 5. 绿色包客户侧前置条件

- Windows 10/11 x64；
- 已合法安装与 MCP 主版本匹配的 TIA Portal/Openness（本交付验证 V21）；
- `Siemens.Engineering.Base.dll` 和 PublicAPI 完整；
- 当前用户加入 `Siemens TIA Openness` 组并已注销/登录；
- TIA 已打开目标工程；
- 若启用 AllowList，登记客户机解压后的实际 MCP EXE 路径；
- 端口 3000 未被其他服务占用，或由客户明确配置其他端口。

## 6. 发布门禁

~~~powershell
node --check tia-mcp-client.js
node --test test/tia-mcp-client.test.js
npm test
git diff --check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\work\green-build\verify-final.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\create-source-handoff.ps1 -KeepDirectory
~~~

最后记录：Git commit、GitHub 远端 SHA、两种 ZIP 的字节数/SHA256、npm 测试数字、绿色冷启动、授权篡改退出码、TIA doctor 结果和已知限制。

## 7. 交接禁区

- 不把真实 `.env`、数据库、授权文件、日志或完整诊断压缩发送；
- 不把 V21 MCP 伪装为其他 TIA 大版本；
- 不为接入方便删除 `localOnly`、确认 token、全局 TIA 队列或敏感静态文件拦截；
- 不把“源码完整交付”描述成“客户无法修改授权”。源码接收者能修改离线授权逻辑，这是必须如实告知的边界。
