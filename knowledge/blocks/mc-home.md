## 5.2　回原点 / 位置清零

**id** `mc-home`
**用到的指令** `MC_Home`

### 名称/别名
**中文**：回原点 · 回零 · 找原点 · 位置清零 · 归位
**英文**：Homing · MC_Home · Reference Point Approach · Position Zeroing

### 适用场景
建立位置基准。**绝对定位（MC_MoveAbsolute）必须先回零**（见 5.5）；相对定位不需要。也用于把累积误差清掉（见「参数与整定」）。

### 梯形图逻辑描述

```
Network 1: 回零许可（✅ 可生成）
  常开[允许发运动指令] 串联 常开[手动或初始化方式]
      串联 常闭[有报警] 串联 常开[原点开关正常]
      →  线圈[允许回零]

Network 2: 回零触发（✅ 可生成，边沿）
  常开[回零按钮] 并联 常开[初始化请求]  → PBox
      串联 常开[允许回零]  →  线圈[回零Execute]

Network 3: 【🔴 手工添加】MC_Home
  Execute ← [回零Execute]
  Axis    ← 工艺对象
  Position ← 原点位置值（Mode 依赖）
  Mode    ← 回零模式（见下）
  输出：Done / Busy / CommandAborted / Error / ErrorID (/ErrorInfo：仅 1200)

Network 4: 完成标志（✅ 可生成，⚠️ 必须边沿捕获，见通用⑤）
  常开[MC_Home.Done] → PBox → SCoil[已回零]
  常开[MC_Home.CommandAborted] → PBox → SCoil[回零被中断]

Network 5: 回零超时（✅ 可生成）
  常开[MC_Home.Busy]  →  T_HomeTmo(IN)，PT = 回零超时
  常开[T_HomeTmo.Q]   →  SCoil[Alm_HomeTmo]，RCoil[回零Execute]

Network 6: 已回零状态的清除条件（✅ 可生成）
  常开[轴掉使能] 并联 常开[有轴错误] 并联 常开[上电首次扫描]
      →  RCoil[已回零]
```

**关于 `Mode` 参数**：回零模式（直接设定 / 主动回零 / 被动回零 / 绝对编码器调整等）的枚举值**因平台与工艺对象版本而异**。
> ⚠️ **本文不给具体枚举值** —— 《运动控制MC指令权威参考》未收录 `MC_Home.Mode` 的完整枚举表，**照抄别处的值有风险**。手工添加时**在博途的指令帮助里现场核对**（选中 Mode 引脚按 F1）。**这属于「未证实，不推断」。**
> 唯一在权威参考中出现的相关事实：`MC_Home(Mode=3)` 参与 S7-1200 的互相 override 清单（见通用②）。

### 参数与整定

| 参数 | 建议初值 | 依据 |
|---|---|---|
| **回原点超时** | **正常回零时间 × 3，且 ≥ 10 s** | **回零可能从最远点开始**（《整定值》2.3） |
| 回零速度 / 逼近速度 | **在工艺对象组态里设**，视机械定 | S7-1200 无 Acceleration 入参，只能用组态值（通用③） |
| 原点位置值 | **视机械定** —— 通常 0.0，或机械零点到工位1的偏置 | 机械参数 |
| **每转一整圈回零一次**（分度累积误差兜底） | 视是否整除定，见下 | 《整定值》1.2 第 3 解法 |

### 🔑 与分度累积误差的关系（《整定值》1.2，这条很实用）

**分度脉冲数 = PPR_out ÷ 工位数**，其中 `PPR_out = PPR_motor × 减速比 i`。
**⚠️ `PPR_out` 必须能被工位数 N 整除**，否则用**相对定位**分度时误差**逐圈累积**。

真实例子（6 工位转盘）：

| 配置 | PPR_out | ÷6 | 结果 |
|---|---|---|---|
| 1.8°、1/8 细分、i=10 | 1600 × 10 = 16000 | 2666.67 | ❌ **不整除** |
| 1.8°、1/10 细分、i=10 | 2000 × 10 = 20000 | 3333.33 | ❌ **不整除** |
| 1.8°、1/8 细分、**i=12** | 1600 × 12 = 19200 | **3200** | ✅ 整除 |
| 1.8°、1/16 细分、i=15 | 3200 × 15 = 48000 | **8000** | ✅ 整除 |

**不整除的后果**：转 60 圈后偏差 ≈ 60 × 0.67 ≈ **40 个脉冲**。工位对不准，气缸下压时**可能撞夹具**。

**三个解法（按优先级）**：
1. **设计阶段选能整除的减速比/细分** ← 最好，从根上消除
2. 改用**绝对定位**（`MC_MoveAbsolute`），目标位置 = 工位序号 × (PPR_out/N)，浮点算，误差不累积
3. **每转一整圈回原点一次**（`MC_Home`）把累积误差清掉 ← 兜底，但增加节拍时间

**交付文档必须写明用的是哪一种，以及为什么**（《整定值》1.2）。

### 常见坑　⚠️【待老殷审】

- 🔴 **`Done` 用轮询而非边沿捕获** → 通用⑤(a)：Execute 提前撤掉时 **Done 只闪一个扫描周期**，轮询代码漏采。**用边沿捕获。**
- 🔴 **`已回零` 放保持性存储区** → 断电期间机械被人推动过，上电后程序仍认为"已回零"，**绝对定位会撞机**。
  → **不放保持区**（除非用绝对值编码器且已正确组态）。
- 🔴 **无回零超时** → 原点开关坏了、机械卡住，轴一直找，无声无息。**必须有超时（正常时间 × 3，≥ 10 s）**。
- **`Mode` 枚举值照抄网上的** → 平台/版本不同枚举不同。**在博途指令帮助里现场核对**（本文明确不给值，属"未证实，不推断"）。
- **回零方向与机械限位方向冲突** → 一回零就撞硬限位。回零方向必须与机械布置一致。
- **原点开关既做回零又做安全限位** → 混用。**安全相关的位置检测必须是直接断开触点**（IEC 60204-1:2016 **10.1.4**，【标准强制】），原点开关通常不是。
- **回零期间允许其他运动指令** → 通用②：**新作业会顶掉 MC_Home**，`CommandAborted = TRUE`，但如果没捕获这个位，程序会以为"回零成功了"。
- **上电不强制回零就允许自动运行** → 位置基准不明。**上电后必须先回零才允许绝对定位**（相对定位可不回零，见 5.5）。
- **`ErrorInfo` 跨平台照抄** → S7-1500 无此输出。
- **报警不监视 `MC_Power.Error`** → 通用⑤(c)。

### 上机前必须确认　⚠️【待老殷审】

- [ ] `Done` / `CommandAborted` **用边沿捕获**（不是轮询）—— Execute 提前撤掉时只闪一周期
- [ ] `已回零` **不在保持区**（断电重启后必须重新回零；实测：断电、手推机械、上电，确认要求重新回零）
- [ ] **回零超时已设**（正常回零时间 × 3，≥ 10 s）并实测触发（挡住原点开关模拟故障）
- [ ] `Mode` 取值已在**博途指令帮助里现场核对**（不是照抄）
- [ ] 回零方向与机械布置一致，**空载试回零成功**（不撞限位）
- [ ] 原点开关**不承担安全功能**；安全限位单独用直接断开触点器件　【标准强制 IEC 60204-1:2016 10.1.4】
- [ ] **上电后未回零时禁止绝对定位**（实测：上电不回零直接发绝对定位，确认被拒且报警）
- [ ] 回零期间禁止其他运动指令，或已正确捕获 `CommandAborted`
- [ ] **分度整除性已核算**（PPR_out ÷ 工位数），采用了 1.2 三解法中的哪一个已写进交付文档
- [ ] 若靠"每圈回零"兜底：回零频次与节拍影响已与甲方确认
- [ ] 报警逻辑同时监视 `MC_Power.Error`
- [ ] 平台差异已核对（Real/LReal、有无 ErrorInfo）
