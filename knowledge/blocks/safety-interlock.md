## 4.2　安全联锁（标准侧）

**id** `safety-interlock`

### 名称/别名
**中文**：安全联锁 · 急停联锁 · 安全链 · 安全门联锁 · 双手启动 · 安全状态读取
**英文**：Safety Interlock (Standard Side) · E-Stop Interlock · Safety Chain · Guard Interlock · Two-Hand Control

> # 🚨 这一节必须读完再写代码
>
> **标准 PLC（非 F-CPU）的程序逻辑不能作为安全功能。**

### 为什么 —— 有明确依据

标准 CPU + 标准 I/O：**单通道、无冗余、无交叉比对、无自诊断**，对应 ISO 13849-1 的 **Category B，上限 PL b**。
而急停最低要求 **PLr c** —— ISO 13850:2015 **4.1.5.1** 原文：
> "…**the minimum required is PLr c or SIL 1**"

**够不着。**

西门子官方《Programming Guideline Safety for SIMATIC S7-1200/1500》**§3.7.5 WARNING** 原文：
> "…**only fail-safe data or fail-safe signals of F-I/O and of other safety programs (in other F-CPUs) are permitted to be processed in the safety program.**"

> Entry ID **109750255** —— ✅ **已核实 REAL**，官方标题逐字：*Programming Guideline Safety for SIMATIC S7-1200/1500*。
> 本知识库另一处出现的 **81318674** 也已核实 **REAL**，但**标题需精确化**：它是合集入口，官方标题为 *Programming Guidelines and Programming Styleguide for SIMATIC S7-1200 and S7-1500 and WinCC (TIA Portal)*，含 4 个章节；常被引用的《Programming Guideline for S7-1200/S7-1500》是其**主附件 PDF 的封面标题**，而 109750255 的内容是其中一章。
> **引用格式（按核查记录建议）**：写成「合集 **81318674** → 章节《Programming Guideline Safety》（亦独立收录为 **109750255**）」的双层格式。
> 依据：《知识库_核查记录_EntryID与PTO》核查 1，证据等级 A，**两个 ID 均无伪造**。

### 所以程序里的「安全联锁」只能做三件事

1. **读安全器件的辅助触点**，用于**状态显示**和**逻辑联锁**
2. **报警锁存与汇总**（走 4.1）
3. **状态机回零**（走 3.1）

**一句话**：标准 PLC 的梯形图可以「**知道**」安全状态、可以做联锁与提示，但**绝不能成为「移除危险能量」这条链上的必要环节**。

### ⚠️ 关于「急停必须硬线」—— 必须区分强制与惯例

核实 BS EN ISO 13850:2015 全文：**hardwired / hard-wired 一次都没出现**。反而 **4.1.3** 的 NOTE 2 明确把电子手段列为合规做法：
> "This can be achieved by declutching, disconnecting, switching off, or **by electronic means** (e.g. a Power Drive System (PDS) in accordance with IEC 61800-5-2)"

即驱动器的 **STO**（对应 Cat 0）、**SS1**（对应 Cat 1）**都是标准认可的实现方式**。

「必须硬线」的真实出处是**旧版** IEC 60204-1（1997/2006）的 **9.2.5.4.2**，该条在 **2016 版 Clause 9 重组后已不以此形式存在**。

**但在本项目场景下（标准 CPU、无 F-CPU、无安全总线），这条惯例应当当成硬规矩执行** —— 因为不用硬线的唯一合规替代是「安全总线 + F-CPU」，成本与论证工作量都不是一个量级。

**→ 知识库和交付文档里一律写【惯例，本项目强制】，不写【标准强制】。** 写错了会被懂行的客户或第三方审核质疑，反而损害可信度。

### 梯形图逻辑描述（**只是读状态，不是安全功能**）

```
Network 1: 读安全状态（全部来自辅助触点，NC 接线 → 程序用常开触点）
  常开[急停回路正常_辅助]      →  线圈[SafeSts_EStop_OK]
  常开[安全门关闭_辅助]        →  线圈[SafeSts_Guard_OK]
  常开[安全继电器输出_辅助]    →  线圈[SafeSts_Relay_OK]
  常开[光栅未遮挡_辅助]        →  线圈[SafeSts_Light_OK]

Network 2: 安全状态汇总（用于联锁与显示，不是切断能量）
  常开[SafeSts_EStop_OK] 串联 常开[SafeSts_Guard_OK]
      串联 常开[SafeSts_Relay_OK] 串联 常开[SafeSts_Light_OK]
      →  线圈[安全状态正常]

Network 3: 安全状态丢失 → 报警锁存 + 状态机回零 + 撤所有动作请求
  常闭[安全状态正常]
      →  SCoil[Alm_Safety]
      →  Move(0) → [步号]
      →  RCoil[允许运行]，RCoil[全部动作请求]

Network 4: 安全状态恢复后 —— 只是「允许再启动」，绝不自动重启
  常开[安全状态正常] 串联 常开[复位按钮] → PBox
      串联 常闭[任一现行安全故障]
      →  RCoil[Alm_Safety]，SCoil[允许再启动]
  ⚠️ [允许再启动] 只是解锁，重启需另一次独立的启动指令

Network 5: 安全门联锁（防误开）—— 运行中锁门（若为带锁门开关）
  常开[设备运行] 并联 常开[惯性未停稳]  →  线圈[门锁输出]
  ⚠️ 门锁的安全等级由机械/安全专业定，本程序只做辅助
```

**双手启动（Two-Hand Control）—— 程序侧只能做辅助**

```
Network X: 双手同时（同步窗口内两手都按）—— 仅作辅助判断
  常开[左手按钮] 串联 常开[右手按钮] 串联 常闭[同步超时]  →  线圈[双手有效]
  常开[左手按钮] → PBox → T_Sync(IN)，PT = 同步窗口时间
  常开[T_Sync.Q] 串联 常闭[右手按钮] → SCoil[同步超时]
  （松开任一手 → 立即撤销 [双手有效]）
```

⚠️ **双手操作装置属 ISO 13851，是人员防护装置，由机械/安全专业设计并用安全器件实现（专用双手控制模块或安全继电器）。** 程序里做的只是"看起来也判断了一下"，**不能作为防护手段**。【惯例，本项目强制：双手控制必须由安全器件实现】

### 参数与整定

| 参数 | 值 | 依据 |
|---|---|---|
| **Cat 1 停机延时** | ❌ **绝不在 PLC 里实现** | 必须由**安全继电器的安全延时输出**或**驱动器 SS1** 实现。理由：PLC 死循环 / CPU 停机 / 程序被改错时，标准定时器不会走完，**动力就永不切断**（《整定值》第三节） |
| 双手同步窗口 | 通常 ≤ 0.5 s（**由安全器件参数决定，不是程序**） | ISO 13851。程序侧不承担 |
| 安全器件最小安装距离 | `S = K × T + C`（ISO 13855） | **T 必须实测**（含真实扫描周期、接触器释放、机械制动时间），**不能仿真、不能算** |
| 安全相关输入的滤波 | **不加长滤波** | 滤波时间直接加进 T，滤波多 50 ms → 安全距离多 100 mm（手速 K=2000 mm/s）（《整定值》2.1） |

### 停止类别与驱动器安全功能的对应（强制映射）

| 停止类别 | 定义 | 驱动器安全功能 |
|---|---|---|
| **Cat 0** | 立即移除动力，**非受控停止** | **STO**（Safe Torque Off，IEC 61800-5-2） |
| **Cat 1** | 受控减速，**停稳后**断动力 | **SS1** |
| Cat 2 | 受控停止，停稳后**动力仍保留** | SS2 |

**【标准强制】急停只能是 Cat 0 或 Cat 1，Cat 2 被明确排除** —— ISO 13850:2015 **4.1.3** 原文只列了 Cat 0 和 Cat 1。类别选择**由风险评估决定**，标准不给硬规则。

**行业惯例（非标准条文）**：
- 大惯量伺服/变频轴 → **Cat 1 (SS1)**。理由：直接断转矩会让重物坠落、机械臂甩出、卷材崩断 —— ISO 13850 **4.1.1.5** 强制要求急停「不产生新的危险」
- 小惯量、断电即停且断电不产生新危险（气缸、小电机）→ **Cat 0 (STO)**

### 常见坑　⚠️【待老殷审】

- 🔴 **把急停串进 PLC 输入，靠程序去断输出** —— **这是本积木存在的全部理由所在的错误。** 标准 CPU + 标准 I/O ≈ Category B（上限 PL b），达不到急停要求的 PLr c。
- 🔴 **用标准 PLC 的 TON 数 Cat 1 停机延时** —— PLC 死循环 / STOP / 程序改错时定时器不会走完，**动力永不切断**。必须用安全继电器的安全延时输出或驱动器 SS1。
- 🔴 **急停复位后自动重启** —— **【标准强制】违规**。ISO 13850:2015 **4.1.4** 原文："**The disengagement of the device shall not restart the machinery but only permit restarting.**" 复位只是"解锁允许再启动"，**重启必须另一次独立的启动指令**。
- **急停回路与安全门联锁回路串在同一条链上** → 复位逻辑、PL 要求、诊断需求都不同，混在一起既难诊断也难论证。【惯例，本项目强制：不串在同一条链上】
- **安全器件按 NO 接线** → 断线时失效且平时看不出来（潜伏失效）。
  **安全相关的位置检测【标准强制】必须是直接断开触点** —— IEC 60204-1:2016 **10.1.4**："Position sensors in circuits with safety-related control functions… **shall have direct opening action (see IEC 60947-5-1) or shall provide similar reliability**"（直接断开触点物理上就是常闭型：IEC 60947-5-1 附录 K，刚性连杆强制断开，**不依赖弹簧**）。
- **急停器件选型不符** → **【标准强制】** ISO 13850:2015 **4.3.3**：急停器件应采用**直接断开动作 + 机械自锁**原则，符合 **IEC 60947-5-5**。（注意：这是**器件要求**，不是布线要求。）
- **接触器无强制导向触点回读** → 无法检测触点粘连。【惯例，本项目强制】没有回读的单接触器方案最好也只到 PL c 附近。
- **保护联结（PE）连续性未实测** → **【标准强制】** IEC 60204-1:2016 **18.2.2 Test 1**，测试电流 0.2 A ~ 约 10 A，**这是首次上电前的强制验证项**。
- **给安全相关输入加长滤波** → 直接放大 ISO 13855 的 S。
- **拿仿真或计算代替 T 的实测** → ISO 13855 的 T **必须实测**（含真实扫描周期、总线抖动、接触器释放、机械制动时间）。**不能仿真、不能算。**
- **引条款不带版本年份** → 条款号对不上，最容易被质疑。
  **现行版本**：ISO 13850 = **2015**；ISO 13849-1 = **2023**（PL↔PFHd 区间未变）；IEC 60204-1 = **2016+AMD1:2021**（EN 版 **EN 60204-1:2018+A1:2025**）；IEC 61496-1 = **2020**。
  ⚠️ **60204-1 的急停条款：2006 版是 9.2.5.x、2016 版是 9.2.3.x** —— **这是最容易引错的地方。**
- **把「急停必须硬线」写成【标准强制】** → 见上，ISO 13850:2015 全文无 hardwired 字样，且 4.1.3 明确允许 STO/SS1。**写成惯例。**
- **在程序里"补"安全功能** → 例如"加一层软件校验就够了"。安全等级是**整条链**的属性，程序里加任何东西都不能把 Category B 抬到 PL c。

### 上机前必须确认　⚠️【待老殷审】

#### 【标准强制】（有明确条款，可引用）

- [ ] 急停复位后设备**不自动重启**，复位只是"解锁允许再启动"，重启需另一次独立启动指令
      —— ISO 13850:2015 **4.1.4**："The disengagement of the device shall not restart the machinery but only permit restarting."
- [ ] 急停器件为**直接断开动作 + 机械自锁**，符合 IEC 60947-5-5
      —— ISO 13850:2015 **4.3.3**（**器件要求**，不是布线要求）
- [ ] 急停功能整体达到 **PL c / SIL 1 以上**，且已由**具备资质人员**评估
      —— ISO 13850:2015 **4.1.5.1**："the minimum required is PLr c or SIL 1"
- [ ] 急停采用 **Cat 0 或 Cat 1**（**Cat 2 被明确排除**），类别选择依据风险评估
      —— ISO 13850:2015 **4.1.3**
- [ ] **安全相关**的位置检测/限位为**直接断开触点**（物理上即常闭）
      —— IEC 60204-1:2016 **10.1.4**
- [ ] **保护联结回路连续性已实测**（测试电流 0.2 A ~ 约 10 A）
      —— IEC 60204-1:2016 **18.2.2 Test 1**，**首次上电前的强制验证项**

#### 【惯例，本项目强制】（无标准条文，但必须执行）

- [ ] 急停回路为**硬线**，经安全继电器**直接切断动力**，**不经过 PLC 程序**
- [ ] 普通停止按钮也按**常闭**接线（断线即停；NO 接线下断线表现为"停不下来"且平时看不出来，是潜伏失效）
- [ ] **Cat 1 的停机延时由安全侧器件计时**（安全继电器的安全延时输出 / 驱动器 SS1），**绝不用标准 PLC 的 TON**
- [ ] 急停回路与安全门联锁回路**不串在同一条链上**（复位逻辑、PL 要求、诊断需求不同）
- [ ] 接触器采用**强制导向（force-guided）触点**做反馈回读
- [ ] **双手控制由安全器件实现**（专用双手控制模块 / 安全继电器），程序侧判断仅作辅助
- [ ] 安全门联锁由**安全器件**实现（ISO 14119 类联锁装置），程序侧的门锁输出仅作辅助
- [ ] 独立于 PLC 的**硬件超温/超压/超速保护**（若存在这类危险）已安装并实测

#### 【分工声明】

- [ ] 人员防护（安全光栅 IEC 61496 / 围栏 / 双手操作 ISO 13851 / 安全门 ISO 14119）由**机械/安全专业**设计，**不依赖本程序**
- [ ] 安全装置的最小安装距离按 ISO 13855 `S = K×T + C` 计算，其中 **T 必须实测**（含真实扫描周期、接触器释放、机械制动时间），**不能仿真、不能算**
- [ ] 风险评估已由具备资质人员完成并签署，本程序的定位（"知道安全状态、做联锁与提示，不承担安全功能"）已写入风险评估文件
- [ ] 引用的所有标准条款**带版本年份**，且已核对（60204-1 急停条款 2006 版 9.2.5.x / 2016 版 9.2.3.x 不要引错）
