## 1.5　手动/自动方式切换

**id** `mode-select`

### 名称/别名
**中文**：方式切换 · 手自动切换 · 手动/自动/检修 · 操作模式
**英文**：Mode Selection · Manual/Auto Switch · Operating Mode Selector

### 适用场景
每个正式工程都要有。至少三态：**手动**（单动作调试）、**自动**（按流程跑）、**停止/待机**。常加**检修**方式。方式位是所有其他逻辑的允许条件。

### 梯形图逻辑描述

**推荐用 Int 表示方式号（而不是一堆互斥 Bool）**：

```
Network 1: 方式解析（以三位旋钮为例，每位一个输入点）
  常开[SW_手动] 串联 常闭[SW_自动] 串联 常闭[SW_检修]  →  Move 1 → [方式号]
Network 2:
  常闭[SW_手动] 串联 常开[SW_自动] 串联 常闭[SW_检修]  →  Move 2 → [方式号]
Network 3:
  常闭[SW_手动] 串联 常闭[SW_自动] 串联 常开[SW_检修]  →  Move 3 → [方式号]
Network 4: 非法组合（多位同时闭合 / 全断）→ 方式号 = 0（停止），并置报警
  ...  →  Move 0 → [方式号]，SCoil[方式故障]

Network 5: 派生允许位（供其他积木串用）
  Eq([方式号], 1)  →  线圈[手动允许]
  Eq([方式号], 2)  →  线圈[自动允许]
  Eq([方式号], 3)  →  线圈[检修允许]

Network 6: 切方式即停（关键）
  Ne([方式号], [方式号_上周期]) → PBox → RCoil[全部运行请求]
  Move([方式号]) → [方式号_上周期]
```

`Eq` / `Ne` / `Move` 全部已实证（`MCPVerify_FC_LAD*.xml`）。

### 变量表

| 名称建议 | 数据类型 | 方向/存储区 | 说明 |
|---|---|---|---|
| `SW_手动` / `SW_Man` | Bool | I | 旋钮触点 |
| `SW_自动` / `SW_Auto` | Bool | I | |
| `SW_检修` / `SW_Maint` | Bool | I | |
| `方式号` / `OpMode` | **Int** | M / DB | 0=停止 1=手动 2=自动 3=检修 |
| `方式号_上周期` / `OpMode_Last` | **Int** | M / DB | 变化检测用 |
| `手动允许` / `En_Man` | Bool | M | |
| `自动允许` / `En_Auto` | Bool | M | |

**为什么用 Int 而不是 Byte**：留扩展空间（总表对步序状态机的同款理由）。

### 参数与整定
无独立整定值。旋钮去抖 10–30 ms（《整定值》2.1），优先用硬件输入滤波。

### 常见坑　⚠️【待老殷审】

- **不处理"非法组合"**：三位旋钮在切换瞬间可能出现全断或两位同时闭合。不处理 → 方式号保持旧值或跳变，设备行为不可预期。**必须显式给出 0（停止）+ 报警**。
- **切方式不停机** —— 自动跑一半拨到手动，自动的自锁位、步序号、气缸输出全挂着。**方式变化必须触发一次全体复位**（运行请求清零、步序回零）。
- **手动方式下没有互锁** —— "手动就是全放开"是最常见的错误认知。手动方式**只解除流程约束，不解除物理互锁**（正反转互锁、上下限位、夹具未松开不许转盘动等一律保留）。
- **检修方式下急停失效** —— 绝不允许。急停在任何方式下都必须有效。
- **方式号在多处被写** → 与双线圈同理。**方式号只允许在方式解析这一个地方赋值**，其他地方只读。
- **用 `Eq` 比较时类型不匹配**。可能报【本机】：
  EN: `Data type '{1}' cannot be converted implicitly into data type '{2}'.`
  EN: `Operator '{1}' is not compatible with the data types of '{2}' and '{3}'.`
  ZH: `编译器信息：类型冲突。`（EN: `Compiler information: Type conflict.`）
  → 🔑 **排"类型不匹配"必须先问块的 IEC check 属性**。官方原文（TIA Info System，*Activate or deactivate IEC check*）："**If 'IEC check for code blocks' is activated, stricter criteria are applied.**" 同一段代码开/关结果不同（例：`TIME→DWORD`、`WORD→BYTE` 仅**关闭**时允许；`BYTE→WORD` 两种模式都允许）。两处开关：`选项 > 设置 > PLC 编程 > 常规 > 新块的默认设置 > 代码块的 IEC 检查`，以及单块属性逐块设置。
- **方式号放保持区** → 断电重启回到"自动"，上电即跑。**方式号不放保持区**，或首次扫描强制 0。

### 上机前必须确认　⚠️【待老殷审】

- [ ] 旋钮**全部位置**（含中间过渡、全断）都试过，方式号行为符合预期，非法组合报警
- [ ] 切方式**确实停机**（在线验证，四个方向的切换都试）
- [ ] **手动方式下物理互锁仍然有效**（逐条列出保留了哪些互锁，现场逐条验证）
- [ ] **任何方式下急停都有效**（逐方式实按急停验证）　【惯例，本项目强制】
- [ ] 方式号不在保持区，或首次扫描强制 0（断电重启不自跑）
- [ ] 交叉引用确认方式号**只有一处写入**
- [ ] 检修方式的使用规程已写进交付文档（谁能用、要不要挂牌上锁）
