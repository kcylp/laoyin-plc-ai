## 1.3　正反转互锁

**id** `interlock-fwd-rev`

### 名称/别名
**中文**：正反转互锁 · 换向互锁 · 正反转控制 · 双向启动
**英文**：Forward/Reverse Interlock · Reversing Starter · Direction Interlock

### 适用场景
电机双向运行（正转/反转），或电动阀开/关、气缸双电控阀。**核心诉求：两个方向绝不能同时输出** —— 对三相电机的正反转接触器，同时吸合就是**相间短路**。

### 梯形图逻辑描述

```
Network 1: 正转
  (常开[正转按钮] 并联 常开[正转运行])
      串联 常开[停止按钮信号]
      串联 常闭[反转运行]          ← 软件互锁
      串联 常闭[换向过渡中]        ← 过渡封锁（见下）
      →  线圈[正转运行]

Network 2: 反转
  (常开[反转按钮] 并联 常开[反转运行])
      串联 常开[停止按钮信号]
      串联 常闭[正转运行]          ← 软件互锁
      串联 常闭[换向过渡中]
      →  线圈[反转运行]

Network 3: 换向过渡计时（推荐做法：任一方向刚断开 → 起一个 TON 封锁另一方向）
  常开[刚停止标志]  →  TON(IN)，PT = 过渡时间
  TON.Q 尚未到 →  线圈[换向过渡中] = 1
```

**结构要点**

1. **两个方向互相串对方的常闭触点**（软件互锁）。常闭 = `Part Name="Contact"` + `<Negated Name="operand" />`，**不是** `ContactNot`（该指令名不存在）。
2. **软件互锁不够，必须加硬件互锁**（见「上机前必须确认」）。
3. **换向必须经过一段"两边都断"的过渡时间**，不能从正转直接切反转 —— 与星三角同理，接触器灭弧需要时间。

### 参数与整定

| 参数 | 建议初值 | 范围 | 依据 |
|---|---|---|---|
| **换向过渡断开时间** | **100 ms** | **50–100 ms**（取上限偏保守） | 交流接触器灭弧时间典型 20–50 ms，取 2 倍余量（《整定值》2.2 星→角过渡同一物理机制） |
| 接触器互检延时（回读确认） | 200 ms | 100–200 ms | 吸合 10–30 ms / 释放 5–20 ms 取余量 |
| 气路换向间隔（若为气缸双电控） | 100 ms | 50–200 ms | 防换向阀频繁动作、气路冲击（《整定值》2.4） |

### 常见坑　⚠️【待老殷审】

- **只做软件互锁 = 迟早烧。** 程序互锁挡不住：接触器**主触点粘连**、线圈**误通电**（外部串线）、PLC 输出模块**点击穿**、程序被改错。这些场景下软件互锁全部失效。
  → **必须硬件互锁**：正转接触器的**辅助常闭**串进反转接触器线圈回路，反之亦然。这是《整定值》2.2 的硬约束原文（星三角同款要求）。
- **直接换向不给过渡时间** —— 正转接触器主触点电弧尚未熄灭，反转接触器已闭合 → 相间短路。
- **过渡时间用运行中改 PT 的方式调** → 🔴 **改了没反应**。官方 Table 7-19："**Changing PT has no effect while the timer runs.**" 必须**先复位定时器**再改。这是"整定值改了设备行为不变"的最常见根因。
- **定时器线圈形式取不到 Q/ET**。官方 p.184："The -(TP)-, -(TON)-, -(TOF)-, and -(TONR)- timer coils **must be the last instruction in a LAD network.**" → 线圈形式必须在**下一个 network** 读 `DB.timer.Q` / `.ET`。（`-(RT)-`/`-(PT)-` 相反，可放中间。）
- **两个方向的输出各自双线圈** —— 同 1.1，F11 自查。
- **没有接触器反馈回读**：接触器该断没断（触点粘连）时程序完全不知道，会在"以为已断"的前提下吸合另一个方向。
  → 有回读才能查粘连。**接触器采用强制导向（force-guided）触点做回读** —— 没有回读的单接触器方案最好也只到 PL c 附近。（【惯例，本项目强制】）

### 上机前必须确认　⚠️【待老殷审】

- [ ] 正/反转接触器的**硬件互锁**（各自辅助常闭串进对方线圈回路）**已实际接线并万用表验证** —— 光靠程序互锁不够
- [ ] 换向过渡时间与**实际接触器灭弧时间**匹配（现场实测：断开一路后示波器/钳表看电流真正到零的时间，取 2 倍）
- [ ] 接触器**强制导向触点回读**已接入，且回读不一致时会报警停机
- [ ] 三相电源相序已确认，"正转"方向与机械期望方向一致（**空载试转过**）
- [ ] 主回路热继电器已接入停止条件
- [ ] 换向过渡期间两路输出**同时为 0**（在线监视验证过）
- [ ] 若为气缸双电控阀：确认阀本身是否已有机械互锁，双电同时得电时的阀内行为已知
