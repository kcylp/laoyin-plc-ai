## 1.4　点动与长动切换

**id** `jog-vs-run`

### 名称/别名
**中文**：点动与长动切换 · 点动/连续 · 寸动 · 手动点动/自动连续
**英文**：Jog vs. Continuous Run · Momentary/Maintained Selection · Inch/Run

### 适用场景
同一台设备既要能"按住走、松手停"（点动，用于对位、穿料、检修），又要能"按一下持续走"（长动/连续）。用一个选择开关或方式位切换。

### 梯形图逻辑描述

```
Network 1: 点动支路（不自锁）
  常开[点动按钮] 串联 常开[点动方式] 串联 常开[停止按钮信号] 串联 常闭[互锁] → 线圈[点动请求]

Network 2: 长动支路（自锁，即 1.1 的起保停）
  (常开[启动按钮] 并联 常开[长动请求]) 串联 常开[长动方式]
      串联 常开[停止按钮信号] 串联 常闭[互锁] → 线圈[长动请求]

Network 3: 汇总
  常开[点动请求] 并联 常开[长动请求]  →  线圈[电机运行]
      （O 块 Card=2）
```

**核心区别就一句话：点动支路没有自锁分支，长动支路有。** 方式位负责选哪一路生效。

**"按一下走一步"（脉冲式点动）的变体**：在点动按钮上加 `PBox`（上升沿），沿触发一次 → 走固定量。此时按住不放**只走一次**，与"按住持续走"是两种完全不同的语义，**必须与用户确认要哪种**。

### 参数与整定

| 参数 | 建议初值 | 范围 | 依据 |
|---|---|---|---|
| 点动速度（若为变频/伺服） | 分度/生产速度 × **0.15** | 分度速度的 **10–30%** | 《整定值》1.4：点动是人眼盯着手动对位用的，人反应时间 0.2–0.3 s。判据是「目标点前 5° 内能靠松手停住」。大惯量取 0.1，小负载取 0.3 |
| 按钮去抖 | 10–30 ms | 10–30 ms | 《整定值》2.1 |
| 点动最短动作时间（防抖出的微动） | 视工艺定 | — | 若现场反馈"点一下走太少不好用"再加，不预设 |

### 常见坑　⚠️【待老殷审】

- **点动支路误加了自锁分支** → 变成"按一下就一直走"，检修时人手还在机器里，**这是伤人的写法**。点动支路**绝不能有自锁**。
- **方式位不互斥** —— 两个方式同时为 1 时两路都通，行为不可预期。方式选择必须**互锁或用单一 Int 表示**（见 1.5）。
- **切方式时不清运行状态**：长动运行中把开关拨到点动，长动的自锁位还挂着 → 松手不停。**切方式必须强制停机**（切换沿 → 复位所有运行请求）。
- **点动与长动共用一个输出但两处写线圈** = 双线圈。必须像上面那样**先汇总再输出**，输出只有一个 `Coil`。
- **脉冲式点动用 `PBox` 时的 M_BIT 陷阱** —— 见 1.6。在被多次调用的 FB 里用 M 位做边沿存储会**互相吞边沿**。
- **点动速度沿用生产速度** → 手动对位时冲过目标点，操作工只能反复来回，最后干脆用手掰。
- **变频/伺服的点动：如果是 MC_MoveJog，注意它是极少数"改速度不用新触发沿就即时生效"的参数**（详见 5.3），而且 **S7-1200 上 Velocity 传负数会被拒（`16#8402`/`16#0024`），S7-1500 静默取绝对值** —— 跨平台移植必须显式取绝对值。

### 上机前必须确认　⚠️【待老殷审】

- [ ] 点动支路**确认无自锁**，松手立即停（**实机松手验证，不是看程序**）
- [ ] 方式开关两位互斥，中间位（都断）时设备不动
- [ ] 切换方式时**强制停机**（在线验证：长动运行中拨开关 → 立即停）
- [ ] 点动速度已现场实测确认「目标点前 5° 内能松手停住」
- [ ] 点动时的**人身防护**已由机械/安全专业确认（点动往往是人最靠近机器的工况）　【分工声明】
- [ ] 检修方式下**急停仍然有效**（急停不因方式切换而失效）　【惯例，本项目强制】
- [ ] 语义已与用户确认：点动是「按住持续走」还是「按一下走一步」
