## 2.5　液位 / 料位控制

**id** `level-control`

### 名称/别名
**中文**：液位控制 · 料位控制 · 高低位控制 · 上下限控制 · 回差控制 · 补水/排水
**英文**：Level Control · High/Low Level Switching · Hysteresis Control · Fill/Drain Control

### 适用场景
用高低两个位式开关（或一个模拟量液位 + 两个阈值）控制泵/阀，把液位/料位维持在区间内。**核心是回差（滞环），不做回差会导致频繁启停。**

### 梯形图逻辑描述

**A. 开关式（浮球 / 电极 / 料位开关）—— 补水场景**

```
Network 1: 低位到 → 启泵；高位到 → 停泵（这就是回差，由两个开关的物理间距提供）
  (常开[低位到] 并联 常开[补水泵运行])
      串联 常闭[高位到]                 ← 到高位即停
      串联 常开[允许运行] 串联 常闭[有报警]
      →  线圈[补水泵运行]
```

即：**低位启、高位停**，中间靠自锁保持。回差 = 高低位开关的物理高度差。

**B. 模拟量式（4-20 mA 液位变送器）—— 用比较器做回差**

```
Network 1: 低于启泵阈值 → 启
  Lt([液位工程值], [启泵阈值]) → SCoil[补水泵运行]
Network 2: 高于停泵阈值 → 停
  Gt([液位工程值], [停泵阈值]) → RCoil[补水泵运行]
Network 3: 报警
  Lt([液位工程值], [低低报警值]) → SCoil[低低液位报警]
  Gt([液位工程值], [高高报警值]) → SCoil[高高液位报警]
Network 4: 传感器故障（信号超出量程）
  Lt([液位原始值], [下限断线阈值]) 并联 Gt([液位原始值], [上限饱和阈值])
      → SCoil[液位传感器故障]
```

`Lt` / `Gt` / `Le` / `Ge` / `Eq` / `Ne` **全部已实证**（`MCPVerify_FC_LAD*.xml`，其中 `Lt` 在**安全 PLC** 上也验证过）。

**排水场景把高低反过来**：高位启排水泵、低位停。

### 参数与整定

| 参数 | 建议初值 | 依据 |
|---|---|---|
| **回差（滞环带宽）** | **视工艺定** —— 由「允许启停频次」反算 | 物理依据：回差越小启停越频繁。**可算**：`回差体积 ÷ 流量 = 一次循环时长`，反过来由「电机允许每小时启动次数」定回差下限 |
| 启停最短间隔（防频繁启停） | **≥ 电机允许启动间隔**，查电机/泵铭牌 | 频繁启停烧电机绕组、损坏泵。**这是器件限制，必须查铭牌** |
| 液位信号滤波 | 0–10 ms（电子输出）；模拟量另加软件平均 | 《整定值》2.1；液面波动需软件滤波（多点平均或一阶滤波） |
| 报警延时（防波动误报） | 3–10 s | 液面晃动、加料冲击造成瞬时越限 |
| 传感器故障判据 | 原始值 < 约 4 mA 对应值 或 > 约 20 mA 对应值 | 4-20 mA 断线时电流为 0，是**天然的断线检测** —— 这是选 4-20 mA 而非 0-20 mA 的核心理由 |

**回差怎么定（不要猜）**：问甲方两个数 —— ① 罐/池的有效容积与截面积；② 泵流量。则「一次循环时长 = 回差高度 × 截面积 ÷ (泵流量 − 用水流量)」。再对照电机铭牌的允许启动频次，把回差调到满足要求。**如果甲方给不出这两个数，就把回差列为「需现场实测调整」，并给出实测方法：先取一个较大回差试运行，记录启停频次，再往下调。**

### 常见坑　⚠️【待老殷审】

- **不做回差，只用一个阈值** → 液位在阈值上下抖动，泵每分钟启停几十次，**几天就烧电机**。这是本积木的头号坑。
- **回差取得太小** → 同上，程度轻一些但仍然超出电机允许启动频次。
- **开关接线形式没确认**：浮球/电极开关有"液位到 → 闭合"和"液位到 → 断开"两种，**接反了逻辑完全颠倒**（补水变排水）。**必须现场把水放掉/加满，实测开关状态。**
- **没有干转保护** → 池子抽空后泵继续转，**几分钟就烧密封/叶轮**。离心泵尤其严重。必须有低低位联锁停泵。
- **没有溢流保护** → 高高位失效时溢出。高高位应有**独立**的联锁（不同的传感器、不同的通道），不能与高位共用一个开关。
- **没有传感器断线检测** → 4-20 mA 断线时读数是 0，程序当"液位最低"→ **泵一直转，直到溢出**。这是最阴的失效模式。**4-20 mA 必须做断线检测（原始值低于 4 mA 对应值即报故障并联锁停泵）**。
- **模拟量比较用 Int 与 Real 混比** → 类型错。相关报错【本机】：
  EN: `Data type '{1}' cannot be converted implicitly into data type '{2}'.`
  EN: `Operator '{1}' is not compatible with the data types of '{2}' and '{3}'.`
  → 🔑 **排类型错必须先看块的 IEC check 属性**（开/关结果不同）。
- **双线圈**：泵输出在液位逻辑、手动、报警联锁三处各写 → F11 必查。
- **液面晃动直接进逻辑** → 加料冲击、搅拌时液面波动造成误动作。**必须加软件滤波 + 报警延时**。
- **料位（固体）用液位思路** → 固体料位有**堆角、挂壁、架桥**问题，单点开关经常误判。料位需要考虑测点位置，有时需多点或雷达/超声。
- **保持性问题**：泵运行位若放保持区，断电重启时不看液位就启泵。

### 上机前必须确认　⚠️【待老殷审】

- [ ] 高低位开关的**实际接线形式已实测**（放水/加水到位，看输入点状态），程序逻辑与之匹配
- [ ] **回差**已确认满足电机/泵铭牌的允许启动频次（实测启停频次记录在交付文档）
- [ ] **干转保护**已实现且实测有效（人为把低低位置真，确认泵停）
- [ ] **高高位溢流联锁使用独立传感器与独立通道**，不与高位共用
- [ ] 4-20 mA **断线检测**已实现，且实测（拔掉信号线，确认报故障 + 泵停）
- [ ] 液位滤波与报警延时已现场调过，搅拌/加料时不误报
- [ ] 泵运行位**不在保持区**，断电重启后按当前液位重新判断
- [ ] 交叉引用 F11 确认泵输出只有一处写入
- [ ] 若为料位（固体）：测点位置已考虑堆角/挂壁/架桥，与甲方确认过
- [ ] 若涉及危险介质（腐蚀、易燃、有毒）：溢流后果与防护措施已由工艺/安全专业评估　【分工声明】
