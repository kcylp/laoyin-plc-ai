## 2.2　气缸往复

**id** `cylinder-reciprocate`

### 名称/别名
**中文**：气缸往复 · 气缸伸缩 · 电磁阀控制 · 伸出/缩回 · 到位检测
**英文**：Cylinder Reciprocation · Pneumatic Cylinder Control · Extend/Retract

### 适用场景
气缸/油缸的伸出与缩回控制，带到位磁性开关（或接近开关）检测。是自动化设备里数量最多的执行机构。

### 梯形图逻辑描述

```
Network 1: 伸出
  (常开[伸出请求] 并联 常开[伸出输出])
      串联 常闭[伸出到位]            ← 到位即停（若为单动作到位保持，此条视阀型定）
      串联 常闭[缩回输出]            ← 互锁
      串联 常开[允许动作]
      →  线圈[伸出输出]

Network 2: 缩回
  (常开[缩回请求] 并联 常开[缩回输出])
      串联 常闭[缩回到位]
      串联 常闭[伸出输出]            ← 互锁
      串联 常开[允许动作]
      →  线圈[缩回输出]

Network 3: 伸出超时
  常开[伸出输出] 串联 常闭[伸出到位]  →  T_ExtTmo(IN)，PT = 伸出超时
  常开[T_ExtTmo.Q]  →  SCoil[伸出超时报警]

Network 4: 缩回超时（同构）
  常开[缩回输出] 串联 常闭[缩回到位]  →  T_RetTmo(IN)，PT = 缩回超时
  常开[T_RetTmo.Q]  →  SCoil[缩回超时报警]

Network 5: 双到位同时（传感器故障）
  常开[伸出到位] 串联 常开[缩回到位]  →  SCoil[到位传感器故障]
```

**多气缸到位汇总（常见做法）**：所有气缸的"缩回到位"串联成一个 `全部原位` 位，作为"允许转盘转/允许下一循环"的条件。总表原文：「到位磁性开关串联汇总是常见做法」。

```
常开[缸1缩回到位] 串联 常开[缸2缩回到位] 串联 … → 线圈[全部原位]
```

### 参数与整定

| 参数 | 建议初值 | 范围 | 依据 |
|---|---|---|---|
| **动作到位超时** | 正常动作时间 × **2**，且 **≥ 1 s** | 正常动作时间 × **1.5–2**，且 ≥ 1 s | 留气压波动、油污增阻、低温变慢余量。**超时即报警，不要无声等待**（《整定值》2.4） |
| 气缸缓冲 / 换向间隔 | 100 ms | 50–200 ms | 防换向阀频繁动作、气路冲击（《整定值》2.4） |
| **保压时间** | ❌ **不给** | — | **工艺参数，必须问甲方** —— 与材料、温度、压力、粘接剂固化特性相关（《整定值》2.4） |
| 到位开关去抖 | 0–10 ms（电子输出）/ 10–30 ms（机械行程开关） | 见《整定值》2.1 | 电子输出无机械弹跳，只需滤电磁干扰 |

**「正常动作时间」怎么得（《整定值》2.4 明确）**：**现场手动打一次，掐表。别算。** 气动系统的实际速度受气源压力、管径、节流阀开度影响太大，算不准。

### 常见坑　⚠️【待老殷审】

- **没有到位超时** → 气管脱落、气压不足、机械卡死时程序**无声等待一辈子**，操作工只看到"设备不动了"，无从判断。**每个气缸动作都必须有超时报警**。
- **超时时间取正常动作时间的 1.05 倍**（"应该够了"）→ 冬天气温低、气缸油污增阻时误报警。现场会把报警关掉，**比没有报警更糟**。
- **不检测"双到位同时为真"** → 磁性开关移位/短路时程序以为气缸同时在两头，逻辑彻底乱。这是**免费的传感器自检**，一定要加。
- **单电控阀与双电控阀混淆**：
  - **单电控**（弹簧复位）：只有一个输出，得电伸出、失电自动缩回。**断电即回原位** —— 这是安全属性，也是限制。
  - **双电控**（双稳）：两个输出，**断电保持当前位置**。断电不回原位。
  - **两个输出同时得电时的阀内行为必须查阀的手册** —— 有的阀会停在中间，有的会以先得电方向为准，有的会串气。**不要假设**。
- **双电控阀两路输出没有互锁** → 见上，行为不可预期，且可能损坏阀。
- **气缸速度靠改 PLC 输出脉宽调** → 错。**气缸速度靠节流阀调**，不是靠程序。
- **到位信号直接用于安全** → 磁性开关不是安全器件。安全相关的位置检测必须是**直接断开触点**（IEC 60204-1:2016 **10.1.4**：`Position sensors in circuits with safety-related control functions… shall have direct opening action (see IEC 60947-5-1) or shall provide similar reliability`）。【标准强制】
- **双线圈**：伸出输出在手动、自动、复位三处各写一个 Coil → 后写覆盖先写。**必须先汇总请求，再单点输出**。
- 🔴 **运行中改超时 PT 无效**（官方 Table 7-19）→ 先复位定时器。
- **气缸带载下压时不做压力/位置确认就进下一步** → 工件没夹紧就转盘旋转。到位开关只说明"缸走到头了"，**不说明工件被夹住**。

### 上机前必须确认　⚠️【待老殷审】

- [ ] 每个气缸动作**都有到位超时报警**，超时时间来自**现场掐表 × 2**（不是估的）
- [ ] "双到位同时为真"的传感器故障检测已加，且已用手拨开关**实测触发过**
- [ ] 阀型已确认（**单电控 / 双电控**），断电后气缸行为已确认并写进交付文档
- [ ] 双电控阀两输出**互锁已实现**，且已查阀手册确认同时得电时的阀内行为
- [ ] 气缸速度已用**节流阀**调好，不是靠程序
- [ ] 到位磁性开关位置已固定并锁紧（防振动移位），且**不承担安全功能**
- [ ] 安全相关的位置检测使用**直接断开触点**器件　【标准强制 IEC 60204-1:2016 10.1.4】
- [ ] 气缸动作路径上的**人身防护**已由机械/安全专业设计　【分工声明】
- [ ] 保压 / 夹紧时间已由**甲方书面提供**
- [ ] 断气/断电时气缸的运动方向不产生新危险（重物坠落 / 夹手）—— 已评估，必要时加单向节流或机械锁
- [ ] 交叉引用 F11 确认每个阀输出只有一处写入
