## 2.1　星三角启动

**id** `star-delta`

### 名称/别名
**中文**：星三角启动 · 星三角降压启动 · Y/△ 启动 · 星三角切换
**英文**：Star-Delta Starting · Y/Δ Starting · Wye-Delta Starter

### 适用场景
三相异步电动机降压启动，减小启动电流冲击。适用于**空载或轻载启动**的场合（风机、泵、空压机）。重载启动不适合 —— 星形下转矩只有角形的 1/3。

**本项目已有样板** `LAD_星三角_FB.xml`（9 触点 / 4 线圈 / 2 RCoil / 1 TON），可作结构参照。

### 梯形图逻辑描述

```
Network 1: 启动锁存
  (常开[启动按钮] 并联 常开[启动锁存]) 串联 常开[停止按钮信号]
      串联 常开[热保护正常] 串联 常闭[有报警]
      →  线圈[启动锁存]

Network 2: 主接触器 KM1（全程吸合）
  常开[启动锁存]  →  线圈[KM1_主]

Network 3: 星接触器 KM_Y
  常开[启动锁存] 串联 常闭[T_Y.Q] 串联 常闭[KM_D]     ← 软件互锁
      →  线圈[KM_Y]

Network 4: 星形运行计时
  常开[KM_Y]  →  T_Y(IN)，PT = 星形运行时间

Network 5: 过渡断开计时（星断开后才允许角吸合）
  常开[T_Y.Q]  →  T_Gap(IN)，PT = 过渡断开时间

Network 6: 角接触器 KM_D
  常开[启动锁存] 串联 常开[T_Gap.Q] 串联 常闭[KM_Y]   ← 软件互锁
      →  线圈[KM_D]

Network 7: 停机 / 报警复位
  常闭[启动锁存] 并联 常开[有报警] → RCoil[KM_Y]、RCoil[KM_D]
```

**时序**：`启动 → KM1 + KM_Y 吸合（星形降压运行 T_Y）→ KM_Y 断 → 过渡断开 T_Gap（两边都断）→ KM_D 吸合（角形全压运行）`

### 星三角的两个死规矩（总表原文，本文只补依据）

**1. 星接触器与角接触器必须互锁 —— 软件互锁 + 硬件互锁双重。**
同时吸合就是**相间短路**。《整定值》2.2 硬约束原文：「星/角接触器除程序互锁外，**必须有硬件互锁**（各自的辅助常闭串进对方线圈回路）。程序互锁挡不住触点粘连和线圈误通电。」

**2. 星→角切换必须有过渡断开时间，不能直接切换。**
物理依据：交流接触器**灭弧时间典型 20–50 ms**，取 2 倍余量 → **50–100 ms**。这个时间的作用是确保星接触器主触点电弧完全熄灭再闭合角接触器 —— **短了就是相间短路**（《整定值》2.2）。

### 参数与整定

| 参数 | 建议初值 | 范围 | 依据 |
|---|---|---|---|
| **星→角过渡断开时间** | **100 ms**（取范围上限，保守侧） | **50–100 ms** | 接触器灭弧 20–50 ms × 2 倍余量（《整定值》2.2） |
| **星形运行时间** | 小电机 **6 s** / 大惯量风机泵类 **15 s** | 小电机 **3–10 s** / 大惯量 **10–20 s** | 依据是电机加速到接近额定转速所需时间。**太短 → 切角时电流冲击大；太长 → 星形绕组过热**（《整定值》2.2） |
| 接触器互检延时（回读确认） | 200 ms | 100–200 ms | 吸合 10–30 ms、释放 5–20 ms 取余量（《整定值》2.2） |

**星形运行时间怎么实测**：用钳形电流表看启动电流曲线，电流下降到接近额定值时即可切角。切太早电流会二次冲高。

### 常见坑　⚠️【待老殷审】

- **只做软件互锁** → 触点粘连 / 线圈误通电 / 输出点击穿时短路。**必须硬件互锁**（《整定值》2.2 硬约束）。
- **不留过渡断开时间** → 星主触点电弧未熄，角已闭合 → 相间短路。
- **过渡时间取 20–30 ms（"看起来够了"）** → 只覆盖了灭弧时间的下限，接触器老化后灭弧变慢就炸。**取 2 倍余量**。
- **KM1 主接触器在切换瞬间也断开** → 电机失电又复电，冲击更大。**KM1 应全程吸合**。
- 🔴 **运行中改 PT 无效**（官方 Table 7-19："Changing PT has no effect while the timer runs."）→ 调星形时间没反应，必须先复位定时器。
- **定时器线圈形式取不到 Q**（官方 p.184）→ 用盒子形式，或下一个 network 读 `DB.timer.Q`。
- **KM_Y / KM_D 各自在多处写线圈**（Network 3/6 各一个 Coil + Network 7 的 RCoil）→ 这已经是**三处写入同一个 Q**。
  ⚠️ **这是本积木最容易出的问题**：`Coil` 每周期无条件赋值，会把 `RCoil` 的复位冲掉。**要么全用 Coil（把复位条件串进 Coil 的逻辑里），要么全用 SCoil/RCoil，不要混用。** 交叉引用 F11 必查。
- **热继电器没接进停止条件** → 过载后接触器仍吸合。
- **没有接触器回读** → 星接触器该断没断（粘连），角吸合瞬间短路。**强制导向触点回读**是唯一能查粘连的手段（【惯例，本项目强制】）。
- **电机接线不适合星三角** —— 电机必须是**六个出线端全部引出**、且**额定电压对应角接**的类型。380V 角接 / 660V 星接的电机才能星三角启动 380V 电网。**这个必须查电机铭牌**。
- **重载启动用星三角** → 星形转矩只有角形的 1/3，起不来，最后长时间闷在星形烧绕组。

### 上机前必须确认　⚠️【待老殷审】

- [ ] 星、角接触器的**硬件互锁**（辅助常闭串联进对方线圈回路）**已实际接线并万用表验证** —— 光靠程序互锁不够
- [ ] 切换过渡时间与**实际接触器灭弧时间**匹配（现场实测灭弧时间 × 2）
- [ ] 主回路**热继电器已接入停止条件**，且 NC 接线
- [ ] **电机铭牌确认**：六出线端、额定电压与角接匹配、允许星三角启动
- [ ] 星形运行时间已用钳形电流表实测确认（电流降到接近额定再切角）
- [ ] 三处写 KM_Y / KM_D 的地方已统一为一种写法（全 Coil 或全 SCoil/RCoil），F11 查过无冲突
- [ ] 接触器**强制导向触点回读**已接入，回读不一致时报警停机
- [ ] 空载试转过：星形→过渡→角形三段时序在线监视确认，过渡期两路输出**同时为 0**
- [ ] 急停独立硬线，不依赖本逻辑　【惯例，本项目强制】
