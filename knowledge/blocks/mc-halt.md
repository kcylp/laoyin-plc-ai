## 5.6　停车

**id** `mc-halt`
**用到的指令** `MC_Halt`

### 名称/别名
**中文**：停车 · 轴停止 · 受控停止 · 中止运动
**英文**：Halt · MC_Halt · Controlled Stop

### 适用场景
让轴以组态的减速度**受控停下**（不是断使能）。用于：正常停机、暂停、报警时的受控停车、方式切换时清运动。

**⚠️ `MC_Halt` 不是安全停车。** 安全停车见 4.2 —— **Cat 0/Cat 1 必须由安全器件（STO/SS1）实现，绝不由 PLC 的 MC_Halt 承担。**

### 梯形图逻辑描述

```
Network 1: 停车触发汇总（✅ 可生成）
  常开[停止请求] 并联 常开[有报警] 并联 常开[方式变化]
      并联 常开[安全状态丢失]
      →  SCoil[停车Execute]
  常开[MC_Halt.Done] 并联 常开[MC_Halt.CommandAborted]
      →  RCoil[停车Execute]

Network 2: 【🔴 手工添加】MC_Halt
  Execute ← [停车Execute]
  Axis    ← 工艺对象
  （S7-1500 另有 Deceleration/Jerk；S7-1200 用组态值）
  输出：Done / Busy / CommandAborted / Error / ErrorID (/ErrorInfo：仅 1200)

Network 3: Done 捕获（✅ 可生成，必须边沿）
  常开[MC_Halt.Done] → PBox → SCoil[已停车]

Network 4: 停车超时（✅ 可生成）
  常开[MC_Halt.Busy]  →  T_HaltTmo(IN)，PT = 停车超时
  常开[T_HaltTmo.Q]   →  SCoil[Alm_HaltTmo]

Network 5: 确认静止后才允许后续动作（✅ 可生成）
```

### 🔴 S7-1500 的特殊规则：`MC_Stop` 顶不掉

通用②里的两条 S7-1500 特殊规则之一：
> **`MC_Stop` 顶不掉**（必须先撤 `MC_Stop.Execute`）

⚠️ **注意区分 `MC_Halt` 与 `MC_Stop`** —— 这是两个不同的指令。《运动控制MC指令权威参考》中明确提到的"顶不掉"规则是针对 **`MC_Stop`**（S7-1500）。
**`MC_Halt` 自身在 S7-1200 上参与互相 override 清单**（通用②：这五条运动指令 + `MC_Halt` + `MC_Home(Mode=3)` + `MC_CommandTable` **互相两两顶掉，无例外**）。
> ⚠️ **`MC_Halt` 在 S7-1500 上是否可被顶掉，《权威参考》未单列** —— **按未证实处理，不推断。** 若工程上依赖，实机验证。

### 常见坑　⚠️【待老殷审】

- 🔴 **把 `MC_Halt` 当安全停车用** → **它是标准 PLC 的普通运动指令**，路径穿过标准 CPU，在 ISO 13849-1 下无法论证（Category B，上限 PL b）。
  **急停/安全停车必须走 STO（Cat 0）或 SS1（Cat 1）**，由安全器件实现。【惯例，本项目强制】
- 🔴 **`Done` 轮询漏采**（通用⑤a）→ Execute 提前撤掉时只闪一周期。**边沿捕获。**
- 🔴 **`MC_Halt` 会被新运动指令顶掉**（S7-1200 明文，互相两两 override 无例外）→ 停车途中发了新运动指令，**轴又跑起来了**。
  **→ 停车期间必须封锁所有运动指令的发出**（这就是 Network 5 `轴静止确认` 的用途）。
- **用 `Done` 就认为"轴已静止"** → `Done` 表示 Halt 作业完成。但**同时活动的其他指令可能还在 Busy**。**建议同时检查所有运动指令的 `Busy` 都为 FALSE。**
- **`MC_Halt` 与 `MC_Stop` 混淆** → 是两个不同指令，S7-1500 上 `MC_Stop` 顶不掉（必须先撤 Execute），`MC_Halt` 的对应规则**未单列，不推断**。
- **报警时立刻去使能而不先受控停车** → 大惯量负载 Cat 0 硬停可能坠落/甩出。ISO 13850 **4.1.1.5** 强制要求急停「**不产生新的危险**」。
  → **行业惯例**：大惯量伺服/变频轴 → **Cat 1 (SS1)**；小惯量、断电即停且不产生新危险 → **Cat 0 (STO)**（《整定值》第三节）。
- **停车超时不处理** → 减速度设得太小、机械卡阻时停不下来，无声等待。
- **报警不监视 `MC_Power.Error`** → 通用⑤(c)。
- **`ErrorInfo` 跨平台照抄** → S7-1500 无此输出。
- **同一实例共用** → 通用⑥。
