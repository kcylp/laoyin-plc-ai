## 5.4　分度定位（相对）

**id** `mc-index`
**用到的指令** `MC_MoveRelative`

### 名称/别名
**中文**：分度定位 · 相对定位 · 步进定位 · 转盘分度 · 增量移动
**英文**：Indexing · Relative Positioning · MC_MoveRelative · Incremental Move

### 适用场景
转盘分度（每次转一个工位）、送料机构定长送料、步进式输送。**竞品 demo 的核心就是这一条。**

### 梯形图逻辑描述

```
Network 1: 分度许可（✅ 可生成）
  常开[允许发运动指令] 串联 常开[自动允许]
      串联 常开[全部气缸原位]        ← 关键联锁：气缸没退回不许转
      串联 常闭[有报警] 串联 常开[安全状态正常]
      →  线圈[允许分度]

Network 2: 分度触发（✅ 可生成，边沿 + 保持 Execute 到 Done）
  Eq([步号], 20) 串联 常开[步内已驻留] 串联 常开[允许分度]
      →  SCoil[分度Execute]
  常开[分度Done] 并联 常开[分度Aborted] 并联 常开[分度Error]
      →  RCoil[分度Execute]              ← Execute 保持到结束，避免 Done 只闪一周期

Network 3: 【🔴 手工添加】MC_MoveRelative
  Execute  ← [分度Execute]
  Axis     ← 工艺对象
  Distance ← [分度距离]        ← ⚠️ 在 Execute 上升沿锁存，之后改无效
  Velocity ← [分度速度]        ← ⚠️ 平台默认值不同！见通用③
  （S7-1500 另有 Acceleration/Deceleration/Jerk）
  输出：Done / Busy / CommandAborted / Error / ErrorID (/ErrorInfo：仅 1200)

Network 4: 完成捕获（✅ 可生成，必须边沿）
  常开[MC_MoveRelative.Done] → PBox → SCoil[分度Done]
  常开[MC_MoveRelative.CommandAborted] → PBox → SCoil[分度Aborted]
  常开[MC_MoveRelative.Error] → PBox → SCoil[分度Error]，Move([ErrorID])→[轴错误码]

Network 5: 到位后机械稳定延时（✅ 可生成）
  常开[分度Done]  →  T_Settle(IN)，PT = 稳定延时
  常开[T_Settle.Q]  →  线圈[分度到位稳定]

Network 6: 分度超时（✅ 可生成）
  常开[MC_MoveRelative.Busy]  →  T_IdxTmo(IN)，PT = 分度超时
  常开[T_IdxTmo.Q]  →  SCoil[Alm_IdxTmo]
```

### 🔑 相对定位的一个官方优势：不要求已回零

| 指令 | 要求已回零？ |
|---|---|
| **MC_MoveAbsolute** | ✅ **要**（两平台 Requirements 都明确列 "The axis is homed"） |
| **MC_MoveRelative** | ❌ **不要**（Requirements 只列 configured + enabled） |

**「未回零也能相对定位」有官方依据。** 这对分度盘很实用：**上电后不回零也能先手动分度对位。**

### 🔴 但相对定位有一个致命的工程陷阱：累积误差

**分度脉冲数 = PPR_out ÷ 工位数**，`PPR_out = PPR_motor × 减速比 i`

**⚠️ `PPR_out` 必须能被工位数 N 整除。** 不整除 → 每次少/多几分之一个脉冲，**误差逐圈累积**。

```
步进电机：PPR_motor = (360° ÷ 步距角) × 细分数
           常见步距角 1.8° → 200 步/转（整步）
           细分 1/2 → 400 ; 1/4 → 800 ; 1/8 → 1600 ; 1/10 → 2000 ; 1/16 → 3200
伺服电机：PPR_motor = 驱动器电子齿轮比换算后的指令脉冲数/转（看驱动器参数，不是编码器线数）
```

6 工位转盘实例（《整定值》1.2）：

| 配置 | PPR_out | ÷6 | 结果 |
|---|---|---|---|
| 1.8°、1/8 细分、i=10 | 16000 | 2666.67 | ❌ |
| 1.8°、1/10 细分、i=10 | 20000 | 3333.33 | ❌ |
| 1.8°、1/8 细分、**i=12** | 19200 | **3200** | ✅ |
| 1.8°、1/16 细分、i=15 | 48000 | **8000** | ✅ |

**后果**：转 60 圈后偏差 ≈ **40 个脉冲**，工位对不准，**气缸下压时可能撞夹具**。

**三个解法（按优先级）**：
1. **设计阶段选能整除的减速比/细分** ← 最好
2. 改用**绝对定位**（5.5），目标 = 工位序号 × (PPR_out/N)，浮点算，误差不累积
3. **每整圈回零一次**（5.2）清掉累积误差 ← 兜底，增加节拍

**交付文档必须写明用哪一种，以及为什么。**

### 🔴 S7-1500 上的一个隐蔽到会让人怀疑人生的坑

> "If you have set **"nm"** as the unit of measurement for an axis, enter a value with magnitude **greater than or equal to 1000.0** at the "MC_MoveRelative.Distance" parameter. **If the amount of the value of "MC_MoveRelative.Distance" is less than 1000.0, the axis will not move during a motion task.**"

**nm 单位轴上 `|Distance| < 1000.0` 会静默不动 —— 不报错。**

### ⚠️ `Distance = 0` / 目标位置等于当前位置：手册未记载

对两份手册全文检索 `Distance" = 0`、`zero distance`、`already at the target` → **全部 0 命中**。
能确定的只有：取值**合法**（在范围内），**不会触发块参数错误**。至于 `Done` 是立即置位还是要等 MinDwellTime —— **手册没写，不推断。**
**→ 若工程上依赖（比如"重复发同一目标位置作幂等处理"），必须实机验证。**

### 参数与整定

| 参数 | 计算式 / 建议初值 | 依据 |
|---|---|---|
| **分度距离（脉冲数）** | **`PPR_motor × i ÷ N`**，必须整除 | 《整定值》1.2。**这是计算值，不可随意改**。缺输入量（步距角/细分/减速比/工位数）**必须向用户索取，不许假设** |
| **分度速度** | `min(PTO上限, 电机可用转速上限) × 0.5` | 《整定值》1.3。**AI 填初值用 0.5 系数**，调试时**往上加不要往下减**（从慢到快是安全方向） |
| PTO 频率上限（约束 A） | **按 Q 点分组，不是按"PTO 1+2 / 3+4"**：<br>**Q0.0–Q0.3（Qa.0–Qa.3）= 100 kHz max / 2 Hz min**<br>**Q0.4–Q1.1（Qa.4–Qb.1）= 20 kHz max / 2 Hz min** | ✅ **已页码级取证**（《知识库_核查记录_EntryID与PTO》核查 2，等级 A，订货号 **6ES7214-1AG40-0XB0** 本体）：S7-1200 系统手册 V4.7（Entry 109977302）"Digital outputs" 表 `Pulse Train Output rate` 行；V4.3.0 **Table A-55, p.1394** 与 **Table 10-36, p.622** 互证；第一方 TED 数据手册三次印证。**V4.3.0→V4.7 数值未变。**<br>🔴 **两条现场最容易踩的约束**：<br>① **脉冲发生器总数上限 = 4**，PWM 与 PTO 共用、每个二选一（手册 p.621 Note / p.464）；<br>② **要凑 4 路 100 kHz 必须放弃方向输出**；每路都要方向输出时，板载**最多 2 路 100 kHz + 2 路 20 kHz**（p.624 Example 1/2）。<br>⚠️ **无 30 kHz 输出档** —— 30 kHz 是 HSC **输入**侧规格（Ia.6–Ib.5），勿混淆。<br>⚠️ **继电器型 CPU（AC/DC/Relay、DC/DC/Relay）板载输出不能做 PTO**，须加信号板（p.1393 脚注 2）。<br>配 SB 1222 200 kHz（6ES7222-1BD30-0XB0）可提到 **200 kHz**，但**仍是 4 路上限**（信号板只提频率不加路数）。<br>**其他型号/订货号仍须自行核对数据手册。** |
| 电机可用转速（约束 B，**通常才是真瓶颈**） | < 300 rpm 最可靠 / **300–600 rpm 常用工作区** / 600–1000 rpm 需查转矩曲线 / **> 1000 rpm 不要用**（转矩不足且易失步） | 步进电机转矩随转速**急剧下降**（绕组电感限制电流建立）。<br>**例**：1/8 细分（1600 PPR）+ 100 kHz → 3750 rpm 是**纸面值**，实际取 300–600 rpm。**PTO 频率上限几乎从来不是瓶颈，电机转矩才是** |
| **加减速时间** | 小惯量分度盘 100–300 ms / **中等惯量转盘 300–800 ms**（竞品那个 6 工位量级）/ 大惯量带料 1–3 s | 理论式：`t = (J_total × ω) ÷ (T_motor − T_load)`，`J_total = 电机转子惯量 + 负载折算惯量(÷i²)`，`ω = 2π×n÷60`。<br>**惯量匹配经验**：`J_load(折算) ÷ J_motor` 宜 **≤ 5**（步进）/ **≤ 10**（伺服）。超了是**选型问题，调参数解决不了**。<br>**减速时间通常应 ≥ 加速时间**（《整定值》1.5） |
| **到位后机械稳定延时** | **300 ms** | 100–500 ms，机械振动衰减时间。**实测法**：工位放百分表或激光位移传感器，到位后看读数稳定到公差带内需多久，取 **1.5 倍**（《整定值》2.3） |
| 分度超时 | 正常分度时间 × 2 | 《整定值》2.5 系数 |

**加减速填错的后果**（《整定值》1.5）：太短 → **步进失步（位置永久丢失，且 PLC 不知道，因为开环无反馈）** / 伺服过载报警；太长 → 节拍拖长。

### 常见坑　⚠️【待老殷审】

- 🔴 **`PPR_out` 不能被工位数整除** → 累积误差，60 圈后 40 个脉冲，撞夹具。**设计阶段就要卡住。**
- 🔴 **参数在 Execute 上升沿锁存，之后改无效**（通用④）→ 改了 Distance/Velocity 但没给新沿，行为不变。**MoveRelative 不在"即时生效"例外内。**
- 🔴 **`Done` 轮询漏采**（通用⑤a）→ Execute 提前撤掉时只闪一周期。**保持 Execute 到 Done，或边沿捕获。**
- 🔴 **`Velocity` 默认值跨平台照抄** → 1200 默认 `10.0`、1500 默认 `-1.0`。在 1500 上写 `-1.0` 是"按组态跑"，搬到 1200 就是 `16#8402/16#0024` 被拒。
- 🔴 **S7-1500 nm 单位轴上 `|Distance| < 1000.0` 静默不动，不报错。**
- 🔴 **加减速时间太短导致步进失步** → **位置永久丢失，而且 PLC 不知道**（开环无反馈）。这是开环步进最凶的失效模式。
- 🔴 **气缸未退回就发分度** → 撞机。**「全部气缸原位」必须是分度的硬联锁。**
- **新作业顶掉旧作业**（通用②）→ SIMATIC 无队列，一律 Aborting。分度途中再发一个分度指令 → 前一个 `CommandAborted`，**位置只走了一部分**，后续全错。**必须等 `Busy=FALSE` 再发下一个。**
- **同一实例给多个运动指令共用** → 通用⑥：状态与错误**互相覆盖**。
- **同时活动命令超限** → S7-1200 `16#8202`（PTO **200** / PROFIdrive·模拟量 **100**），「活动」= `Busy=TRUE`。
- **报警不监视 `MC_Power.Error`** → 通用⑤(c)。
- **`Distance = 0` 的行为当已知用** → **手册未记载，不推断，要实机验证。**
- **惯量比超标却想靠调参数解决** → `J_load/J_motor > 5`（步进）是**选型问题**，要加大减速比或换电机。
- **`ErrorInfo` 跨平台照抄** → S7-1500 无此输出。

### 上机前必须确认　⚠️【待老殷审】

- [ ] **`PPR_out ÷ 工位数` 已核算整除**；不整除时采用的解法（改减速比/改绝对定位/每圈回零）已写进交付文档
- [ ] 分度距离是**按公式算出的**（注释里写出计算式和代入量），不是估的
- [ ] 分度速度按 **`min(PTO上限, 电机可用转速) × 0.5`** 填初值，**调试从慢往快调**
- [ ] **PTO 频率上限已按确切订货号的数据手册核对**（不是照抄 100 kHz）
- [ ] 加减速时间已从长往短调至出现失步再退回 **1.5 倍**，并记录
- [ ] **惯量比已核算**（`J_load(折算)/J_motor` ≤ 5 步进 / ≤ 10 伺服）
- [ ] 到位稳定延时用**百分表/激光位移传感器实测**（读数稳定到公差带内的时间 × 1.5）
- [ ] **「全部气缸原位」是分度的硬联锁**（实测：手动让一个气缸伸出，确认不许分度）
- [ ] `Execute` **保持到 Done**（或 Done 用边沿捕获）
- [ ] 分度期间**不会被抢发新指令**（等 `Busy=FALSE`）
- [ ] `Velocity` 值与**平台**匹配（1200 不能负；1500 的 -1.0 含义是"用组态"）
- [ ] 若轴单位为 **nm**：`|Distance| ≥ 1000.0`
- [ ] 报警逻辑同时监视 `MC_Power.Error`
- [ ] `MC_MoveRelative` 使用**独立实例**
- [ ] **分度一整圈（N 次）后用百分表看回到原点的偏差**（这是验证整除性的实测方法，《整定值》第四节）
- [ ] 分度超时已设并实测
- [ ] 平台差异已核对（Real/LReal、ErrorInfo、Acceleration 入参、Velocity 默认值）
